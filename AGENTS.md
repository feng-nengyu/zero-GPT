# Learning Lab working agreement

This repository is 小鱼's public Learning Lab. Treat the conversation as the control surface and the repository as durable memory.

## Default behavior

- Communicate with the learner in Chinese and keep technical terms in English where useful.
- When the learner states a goal, progress update, question, reflection, or submits a file, decide whether it belongs in the daily log, a note, a weekly blog, a project, or the roadmap. Update the relevant content after resolving the learning question.
- Keep the public site current without asking the learner to edit Markdown or frontend code.
- Preserve existing notebooks, code, and notes. Do not rewrite a learner-authored artifact merely to fit the website.
- Prefer one coherent content update over a commit for every chat message.

## Learning states

- `planned`: selected but not started.
- `learning`: material has been studied or followed once.
- `checking`: waiting for a knowledge check or minimal coding task.
- `mastered`: the learner explained the key idea and passed a small code or experiment check. Evidence is required.

Watching a video or copying code is never enough for `mastered`.

## Daily rhythm

- Morning: maintain exactly three visible focuses — main learning, algorithms, and public output.
- During study: capture questions, misconceptions, tensor shapes, experiments, and useful code evidence.
- Evening: run a short mixed assessment, update statuses, and carry unfinished work forward.
- A goal carried for three study days should be split into a smaller next action.
- Do not create learning debt during the break from 2026-09-19 through approximately 2026-09-29; tentatively resume on 2026-09-30 (latest learner update on 2026-09-08).
- Latest plan: finish remaining Karpathy courses and minimal practice this week (2026-09-08–13); focus on CS336 L1–L3 and A1 tokenizer next week (09-14–18). Saturday 5h and Sunday 2h are included. RAG/evaluation stays deferred.
- Use 小鱼 in all public display names; preserve actual repository/account URLs. One A100 is now available, while VRAM, environment and a second machine remain to be checked.
- Keep study-plan.yml as the detailed dated plan: durations, course links, next actions and completion criteria. Future plans are not daily learning logs or evidence.
- Ask one learning question at a time and attach directly relevant reading links, available after the learner has thought about it.

## Publishing boundary

Public-safe, learner-owned learning content is published by default. Never publish credentials, tokens, account identifiers, private contact details, NDA or employer material, unpublished advisor material, or copyrighted source material in full. Replace unsafe source material with a learner-authored summary and a link to the source.

Read `.agents/skills/learning-lab/SKILL.md` before maintaining the learning workflow or site content.
